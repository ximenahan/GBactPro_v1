# GBactpro

**Bacterial promoter prediction from short DNA windows (binary classification).**

GBactpro scores whether a fixed-length DNA sequence is a promoter. Version 1 ships the best short-segment setting from the paper (**Type 1 / setting 1**: Minus35 + Spacer + Minus10) as a ready-to-run CLI, plus a cleaned E. coli genome-wide reproduction pipeline.

---

## What you need to prepare

| Item | Requirement |
|------|-------------|
| Sequence length | **27–31 bp** (core promoter window). Sequences are **post-padded** to maxlen **31**. Lengths &gt; 31 are rejected. |
| Input format | DNA **FASTA** (`A/C/G/T`; `U` accepted as `T`). No `N`. |
| Output | TSV with `id`, `sequence`, `length`, `score`, `prediction`, `threshold` |

`score` is a sigmoid probability in `[0, 1]` (higher = more promoter-like).  
`prediction` is `promoter` if `score >= threshold` (default **0.5**), else `non-promoter`.  
For ranking or PR/ROC analyses, use the raw `score` column rather than the hard label.

## Installation

### Option A: conda (recommended)

```bash
git clone <this-repo-url> GBactpro
cd GBactpro
# Large weight files use Git LFS (>100 MB). Install git-lfs, then:
#   git lfs install && git lfs pull
conda env create -f environment.yml
conda activate gbactpro
./setup.sh
./test.sh
```

### Option B: Docker

```bash
docker build -t gbactpro .
docker run --rm -v "$PWD/example:/data" gbactpro \
  -i /data/input/sequences.fasta \
  -o /data/output/predictions.tsv
```

## Predict (v1 entrypoint)

```bash
python scripts/gbactpro_predict.py \
  -i example/input/sequences.fasta \
  -o results/predictions.tsv \
  --model models/type1_35s10_random \
  --threshold 0.5
```

### Parameters

| Flag | Default | Meaning |
|------|---------|---------|
| `-i` | required | Input FASTA |
| `-o` | required | Output TSV path |
| `--model` | `models/type1_35s10_random` | SavedModel directory |
| `-t` / `--threshold` | `0.5` | Hard call threshold |
| `--batch-size` | `256` | Inference batch size |

### Example

- Input: [`example/input/sequences.fasta`](example/input/sequences.fasta) (5 promoter + 5 non-promoter E. coli windows)
- Output: [`example/output/predictions.tsv`](example/output/predictions.tsv) (regenerated by `./test.sh`)

### Apply to your own data

1. Extract **27–31 bp** windows corresponding to candidate core promoters (Minus35–Minus10 style), or any DNA of that length you want scored.
2. Save as FASTA.
3. Run `gbactpro_predict.py` as above.
4. Rank by `score`, or threshold with `-t` for binary calls.

## Reproducing paper genome-wide analysis

See [`paper/genome_wide/README.md`](paper/genome_wide/README.md).

```bash
conda activate gbactpro
cd paper/genome_wide
./run.sh --quick   # 100 kb smoke demo
./run.sh --full    # full E. coli chromosome (slow)
```

Steps: prepare genome/TSS → load pre_max29bp model → double-strand scan → one-to-one PR evaluation → `metrics.json`.

## Method (short)

CNN + BiLSTM binary classifier on one-hot DNA. Type 1 windows cover the bacterial core promoter (Minus35 + variable spacer + Minus10). Training used pooled positives from 43 species with genomic random negatives (1:10). Genome-wide evaluation slides the window across both strands and matches predictions to TSS-anchored promoter intervals with greedy one-to-one assignment.
